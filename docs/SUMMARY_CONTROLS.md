# 摘要页按键提示的小字右对齐

这一组件公开项目自有的72字节局部包装器，与现有120字节小字测量核心配合。它读取原生窗口的位置和宽度，计算底部提示的横坐标，然后返回各游戏的原生打印流程。源码不包含提示正文、字体、图标或原生游戏例程。

已分别核对火红2.3／0111、火红2.4／0112、叶绿2.3／R89及叶绿2.4／R90的精确镜像。2.4沿用对应2.3的这部分代码；这不是说两个完整版本相同。旧配置的SHA和适用范围保留。

| 项目 | 火红 | 叶绿 |
|---|---|---|
| 包装器文件偏移 | `0x7B84C8` | `0x6D5000` |
| 测量核心文件偏移 | `0x7B8450` | `0x6D5048` |
| 局部调用桥文件偏移 | `0x1375E8` | `0x1375C0` |
| 原生继续执行入口 | `0x081375F1` | `0x081375C9` |
| 包装器SHA256 | `f4d419c6d065b3bf7f7643c409ced7cf9b55a5fc761dcb9d7d5d0677e8c82602` | `982e4f33c65207d87d2fc0f2169f41cbdb2edaeeb1fe69a143b0192492ec6434` |

以上文件偏移仅用于核对指定成品，运行地址需加`0x08000000`。它们不是原版空闲区或安装许可。

## 源码与使用

源码是`shared/patches/summary_controls.s`，由编译器为两个版本分别绑定`SMALL_MEASURE`和`SUMMARY_CONTINUATION`。无游戏输入也能编译：

```sh
python3 -B tools/renderer_module.py compile --profile firered-2.4-0112
python3 -B tools/renderer_module.py compile --profile leafgreen-2.4-r90
```

编译结果包含`summary_controls`和`small_measure`，仍不是原版完整安装器。可用`--output-dir`写入一个新目录。核对自己持有的对应成品使用：

```sh
python3 -B tools/renderer_module.py verify --profile firered-2.4-0112 --rom my_fr_2_4.gba
python3 -B tools/renderer_module.py verify --profile leafgreen-2.4-r90 --rom my_lg_2_4.gba
```

核对器拒绝错误身份、错组件和错误调用桥；仅证明所选组件与指定成品一致。

## 调用约定与排版规则

这是接在特定原生函数内部的桥，不能当作任意C函数调用。入口`r0`为原生窗口编号，`r6`为已验证的单行提示；调用者已建立原生栈参数。包装器保留窗口编号、`r4/r5`及原LR；测量核心保留其要求的寄存器。返回原生继续入口时，`r1=0`、`r2`为横坐标，原栈`[sp+4]=0`、`[sp+8]=r6`，`[sp]`保持。

窗口描述符在原生RAM的`0x02020430`，每项12字节；`+1`和`+3`分别给出左边界和宽度，单位8像素。有效原生窗口满足左边界在屏幕可用范围内。右边界取窗口右侧与236像素中的较小者，再减去窗口左侧，得到窗口内部可用宽度。提示放得下时，用可用宽度减文字有效范围；放不下时沿用生产代码的`x=8`回退。

`x=8`不会自动折行，也不保证过长文本可见；左边界超出236像素还可能发生无符号减法回绕。这些不是通用安全输入。修改者应先用`tools/measure_small.py`验证自己提供的文本与窗口，再进行实际页面检查；不能把包装器源码匹配当作任意布局都安全。

测量核心的已支持token及前置约束见[测宽说明](WIDTH_SCANNERS.md)。生产汇编依赖审定过的输入，没有自动添加范围检查或改变全局字体策略。

## 合成CPU验证

```sh
python3 -B tools/check_summary_controls_cpu.py --mgba-prefix /path/to/mgba
```

使用本地GNU Arm、C编译器和mGBA开发库。测试全部自行生成内存、文本和字宽，不读取游戏、字体、存档或第三方图像。每版用12种token流、6种窗口布局分别执行ROM入口与共同搬到RAM的包装器／测量器，共144个用例；检查计算结果、原生栈参数、LR、保留寄存器和边界哨兵。故意错误的字宽和原生继续入口必须失败。

测试停在原生继续入口之前，原生绘制例程没有执行。因此它不是实际菜单画面、完整原生流程、Delta或GBARunner3实机验收。其余小字包装器、字体分流链和原版安装编排仍待整理。
