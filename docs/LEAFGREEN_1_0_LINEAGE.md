## 实际重放：八个局部步骤

| 步骤 | 本地输入与公开方法 | 独立留存子版比较 |
|---|---|---|
| FIX554→555 | 读取父版活文本token，只删WAIT后冗余NL；无需外部字表或译文 | 整枚相同；177 B／2范围 |
| FIX555→556 | 读取父版两条活文本，将16个旧私有标点换为原生码 | 整枚相同；266 B／10范围 |
| FIX556→557 | 固定父SHA，交换WAIT与感叹号顺序；不需要译文或字表 | 整枚相同；2 B／1写入范围 |
| FIX557→558 | 独立父ROM＋外部原清单＋本地字表重新编码，验证指针前像与相对位移 | 整枚相同；380 B／33范围；16条重定位 |
| FIX558→559 | 同上，另验证一条原位文本的容量与FF填充 | 整枚相同；344 B／16范围；5重定位＋1原位 |
| FIX558＋559＋四到七岛560→561 | 三输入固定SHA、不重叠合并 | 整枚相同；344＋30880＝31224 B；重叠0 |
| FIX581→582 | 独立归档581＋本地原版及供体，标题构建API | 整枚相同；6209 B／4范围；不再仅是恢复父本夹具 |
| FIX582→583／最终1.0 | 独立归档582＋本地字表，提示构建API | 与真实保留最终1.0相同；15 B／2范围 |

入口分别为leafgreen/rebuild_layout555_556.py、leafgreen/rebuild_557_559.py、leafgreen/rebuild_merge561.py和leafgreen/rebuild_1_0_tail.py。均非原版到完整汉化构建器；其中558/559是**外部清单重新编码与前像重放**，不是旧脚本的发现条目、消费者可达性或语义测试算法重跑。标题资源来自用户本地供体，不随源码分发。

FIX556清单的old_stream字段是更早版本地址0xE372B8／0xE37C64，实际父版活指针为0xE3805C／0xE380A8。新布局工具以生效指针为前像依据，既不照抄过时元数据，也不修改旧清单。555／556无需译文或字表，转换只发生在token边界，不误改参数／字形内部字节。

首批还从兼容备份字表精确重放558/559。备份SHA为`464c5ab50700544e349c07217ef949d2ac7cf2566bbdf89737854bc4863fabd4`；当前兼容字表SHA为`3a50c6f6d93a3caefb382102cfe4a1217694617d6e7b04a0e435801f61234c8a`。兼容不证明备份就是FIX558当时使用的原始快照；字表不公开。

父ROM改坏一字节、外部清单多一空格、已用字符gid变更均被公开构建API拒绝。合成测试另覆盖前缀位移、旧指针错误、非FF池、写入重叠、容量、最终SHA与生产CLI错误身份拒绝。
