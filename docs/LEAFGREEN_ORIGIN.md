# 从叶绿汉化源头追溯

本批按叶绿的起点调查，不从火红末端补丁倒推成完整历史。输入身份重新核验，报告与源码分开取证；原始字模、译文、ROM 均未公开。机器证据摘要见 [LEAFGREEN_ORIGIN_EVIDENCE.json](LEAFGREEN_ORIGIN_EVIDENCE.json)。

## 已确认的起点

最初同时持有三份输入：日版叶绿 BPGJ Rev0、美版叶绿 BPGE Rev0，以及美版汉化叶绿供体。三者均为 16 MiB，本次重新计算 SHA 与最早第一阶段报告一致。

| 输入角色 | SHA-256 | 用途 |
|---|---|---|
| BPGJ 原版 | `2957b392dc09fc8df45a660af5493368d7bd378d299862f4cc115998e9da0bf2` | 日版汉化的基础游戏 |
| BPGE 原版 | `78d310d557ceebc593bd393acc52d1b19a8f023fec40bc200e6063880d8531fc` | 与美版汉化比较、建立符号对应 |
| BPGE 汉化供体 | `8a74df389bd5504bc09939fcb5c9e0c277f916024dfbd4db4bf46eb46936aafc` | 部分中文字模、早期开场文本及后来的资源导入 |

美版原版用于研究，不应被误写成每个日版构建的运行依赖。拥有输入文件、知道哈希或知道作者，并不能据此认定具备再分发许可。

## 早期过程：实验不是线性父版链

1. 第一至第五阶段主要是只读比较、符号／字体定位。早期 `RenderText` 候选后来曾被否定，不能沿用旧候选地址当最终事实。
2. MVP01/MVP02 用项目手绘测试字探索原生字形槽；MVP03 探索独立私有 F7 编码。不同实验的字模排列、终止符和编码曾有变化。它们不是可直接套用今天全部文本的成熟构建器。
3. MVP04 开始记录从美版汉化供体导入真实字模；MVP05 的源码明确从供体读取三字测试素材；MVP06 从供体读取整段开场文本和对应字模；MVP08 扩展到五段开场文本。
4. MVP09 是冻结验证产物。Phase8 报告与重定位器说明后续应重新从干净 BPGJ 构建，而不是拿 MVP09 当串行父版。
5. Phase8 引入 UTF-8 资源表、私有编码器、固定分配和来源字表。开场五段后来改为 Unicode 文本输入，但所用字模仍由来源记录从供体读取；变为 Unicode 并没有消除资源来源问题。

这些结论分别有源码与历史报告支持，但本批没有重建已经缺少历史输入快照的每个 MVP。报告里的历史 Delta 验证不等于本批重新运行了模拟器。

## 当前 R87 仍保留什么来源

本次读取现用字表（SHA `3a50c6f6d93a3caefb382102cfe4a1217694617d6e7b04a0e435801f61234c8a`），共 2377 行：

- `uscn_custom`：2356 条；`uscn_male`：6 条；`sanitized`：2 条；`generated`：13 条。
- 状态分布为 2366 条 verified、10 条 reserved_alias、1 条 allocated。行数不能当作独立字形总数。
- 读取 R87 的实际运行页表，再按每条 `uscn_custom` 记录重组当前 64B 字模，与供体相应 atlas 比较：**2356/2356 条逐字节相同**，0 条越界，0 条来源码不合法。

这项逐字节比较只覆盖当前统一／male 私有字模与 `uscn_custom` 记录；没有把其它 21 条来源、所有小字体副本或全部 UI 图块算成已比对。源代码里也存在使用系统字体生成字模的旧工具；`generated` 这个标签不能自动当作素材已获 MIT 许可。

另外，FIX582 历史报告明确记载中文标题图块／地图来自供体。该报告的来源说明已检查，本批没有逐像素复审当前标题，也没有公开该图像。

## 本批补入的源码

- `shared/frlg/encode.py`：源于叶绿编码器；只接收用户本地字表，不附译文或字模。公开版本关闭 RAW 绕过、检查重复 gid 和控制流结构。
- `shared/frlg/font_pages.py`：叶绿 FIX348 页表及页内地址逻辑，不含字模。公开版本额外拒绝旧变体写入后来预留的页表／新字库窗；不是完整游戏资源分配器。
- `shared/frlg/glyph_codec.py`：从叶绿早期原生字模研究整理出的 source codec；原生 lookup 表只从用户提供的原版 ROM 读取。
- `leafgreen/experiments/first_glyph.py`：从干净 BPGJ 生成一个手绘测试字的小实验，采用后来修正的 codec。它不是历史 MVP01 的逐字节复刻，也不是完整汉化。

本批所有修订只在公开仓库发生，原叶绿脚本、字表和正式 ROM 不改。完整字体、Unicode 字表、译文、标题资源仍需要逐项核清来源和公开条件；不能给供体素材统一套 MIT。
