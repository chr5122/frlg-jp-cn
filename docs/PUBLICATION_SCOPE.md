# 首批公开范围与未完成项

本次为两个项目创建共同的干净源码仓库，不改动游戏开发基线。公开内容已经过逐文件筛选，不是把原工作目录改成公开仓库。

## 可使用的部分

1. 公共只读解析和差异验证模块，可用于自己合法持有的输入；JP/CN 模式必须显式指定。
2. 两版冒险回顾盒子显示的独立入口汇编；需要对应历史父版中的显示 alias、准确调用点和资源台账，不能直接打到原版。
3. 固定 BUILD0107 的范围修复器，默认在内存中验证结果；可显式另存 BUILD0108，不能产出完整 2.2.2。
4. 合成测试和发布门禁：不需要 ROM、字体或存档。
5. 叶绿起点研究的编码器、页表和 source codec，以及从原版构建的手绘单字小实验；不含供体资源。起源追溯与当前字模来源比较见 `LEAFGREEN_ORIGIN.md`。这不代表完整历史构建链已闭合。
6. 历史清单只读适配器与叶绿1.0末端构建器：需要用户本地父版／字表，标题导入还需本地供体，不携带这些数据。不能把它们称为原版到2.2.2完整构建链。
7. FIX557～559局部复现入口及独立归档身份补证：558/559的原译文清单和字表仍为外部私有输入，不随代码上传；不执行旧发现算法、不包含二进制差分载荷。
8. FIX555／556活文本token变换器：只需精确历史父版，不需外部译文或字表；固定旧指针、变换与最终SHA。不分发游戏正文或字模，不从子版提取载荷。
9. FIX553外部清单复现器与554历史布局入口：553原译文清单仍不公开；554明确复现当时的标点回归，非现行修复。既有公共RAW禁用规则不放宽，不携带译文、字表或二进制差分。
10. 双版本日版原版的固定身份字节清单入口；清单由调用者自行审核，不提供完整汉化配方。
11. 自备字形的独立页／字表打包工具和参数化ARM7四图块解码核心；不包含字体素材，不读取供体，也不自动安装进原版。
12. 两版精确原版的新游戏首句显示实验：自备字形、限定私有字符和整串RAM身份守卫，不借用历史低ROM洞，不作为通用中文引擎或完整汉化发行。
13. 火红现行学习器名称独立读写生产源码、固定名称槽资源接口、精确依赖核对和纯合成mGBA CPU夹具；不携带招式译文、ROM或原游戏复制例程源码。
14. 两版所选生产渲染组件及只读核对器：普通／小字解码、窄标点字宽、所选分流入口；不含完整分流链、字库资源或原版生产安装器。
15. 当前F7测宽分派、宽度别名及下一层字体入口，以及无游戏输入的可选CPU测试。叶绿变宽原生回退落入表数据的隐患保留并显式报告；源码匹配不能作为安全验收。
16. 独立叶绿R90回退修复器：精确R89和日版原版为外部输入，单字节修正、编译匹配及完整输出SHA验证；不提供任何ROM，不晋升或上传候选。
17. 自备小字页／宽度表打包及普通字编号配对；可选合成CPU测试只使用调用者自行生成的测试像素和独立回调，不含字体素材。
18. 两版小字测量核心源码与单行离线测量检查；调用者自备所有宽度数据。可选合成CPU回调不含原游戏字体、图标数据及原生例程。

## 尚未公开／不能重建的依赖

| 内容 | 当前处理 | 后续条件 |
|---|---|---|
| 原版或汉化 ROM、SAV、即时存档 | 不上传 | 用户本地合法持有，永不纳入 Git 历史 |
| 完整译文、字库及图块 | 暂不上传 | 逐项确认来源、署名与公开再分发许可 |
| 早期中文基础引擎／供体资源 | 未打包 | 核清可再分发实现或替换为有明确授权的源码 |
| 历史构建器与大批适配器 | 未整体公开 | 拆除私人路径、补全依赖、逐文件审阅后分批引入 |
| 调试运行器、截图和采证日志 | 未打包 | 去除存档、私人资料和游戏图像；提供可复现流程而不是原始目录 |
| 全部资源预留台账 | 尚未完整移植 | 依赖链必须完整，不可只凭公开的局部窗口重新分配空间 |

因此本仓库当前不能作为完整构建发布包，也不能将合成测试通过称为两版全游戏验证通过。没有上传二进制差分补丁；以后如发布，仍需独立审查其内容与依赖。

## 不改变的工程约束

- 显示修复不向昵称、OT、PID、箱名等存储字段回写中文，不改变存档格式。
- 不复用完整预留窗口中的 FF 尾部；空白不等于可分配。
- 不以固定 LR／返回地址猜读写用途；镜像执行需要单独覆盖。
- 结构门禁、字节迁移、受控显示和原生剧情验证是不同层次。
- 所有新增消费者都需本版证据，不从另一版本机械加减地址。
